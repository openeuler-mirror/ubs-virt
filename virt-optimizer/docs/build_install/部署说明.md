# 部署说明

## 环境要求

### 获取软件包

ubs-optimizer的发布件如下：

| RPM包                                             | 说明                                      |
|:-------------------------------------------------|:----------------------------------------|
| ubs-optimizer-\<version>-\<release>-\<arch>.rpm | 主程序包，包含配置、采集工具和优化分析工具等；`<arch>` 为 `x86_64` 或 `aarch64` |

### 系统要求

| 项目 | 说明 |
|:-----|:-----|
| 推荐操作系统 | openEuler 24.03 LTS SP4 |
| CPU 架构 | 支持 `x86_64` 和 `aarch64` |
| 用户权限 | 安装与管理需 `root` 权限 |

支持的硬件场景：

| CPU 架构 | 硬件环境 |
|:---------|:---------|
| `aarch64` | 鲲鹏型号 CPU、昇腾型号 NPU；Atlas 900 A3 SuperPoD 超节点 A900、A3 SuperPoD 超节点、Atlas 800T A2 训练服务器、A800T A2 训练服务器 |
| `x86_64` | 昇腾型号 NPU；G8600 服务器 |

## 软件安装

> 宿主机和虚拟机均需要安装 `ubs-optimizer` RPM 包。  
> 安装 RPM 包前，请确保操作系统已加载 `vsock` 内核驱动：
>
> ```bash
> modprobe vsock
> ```

1. 在宿主机安装ubs-opt性能优化工具

   ```bash
   rpm -ivh ubs-optimizer-<version>-<release>-<arch>.rpm
   ```

2. 物理机安装完成后，在虚拟机安装ubs-opt性能优化工具

   ```bash
   rpm -ivh ubs-optimizer-<version>-<release>-<arch>.rpm
   ```

   命令回显示例如下：

   ```terminal_output
   rpm -ivh ubs-optimizer-0.1.0-k5.1-aarch64.rpm
   Verifying...                          ################################# [100%]
   Preparing...                          ################################# [100%]
   Updating / installing...
      1:ubs-optimizer-0.1.0-k5.1         ################################# [100%]
   ```

### yum SSL 证书校验异常

如果使用 yum 安装软件时提示 SSL 证书校验失败，应优先执行以下检查：

```bash
date
timedatectl status
rpm -q ca-certificates
curl -Iv https://repo.openeuler.org/
env | grep -i proxy
```

如果服务器使用代理，且代理使用自签名证书或内部 CA 签发的证书，建议将可信的根 CA 加入系统信任库：

```bash
cp <可信根CA证书>.crt /etc/pki/ca-trust/source/anchors/
update-ca-trust extract
```

在暂时无法修复证书问题且网络环境可信的情况下，可将 `sslverify=false` 作为备选方案。优先使用只对当前命令生效的配置：

```bash
yum --setopt=sslverify=false install <软件包名>
```

如果确实需要对特定软件源临时关闭校验，可在 `/etc/yum.repos.d/` 下对应的 `.repo` 文件中，仅在目标软件源配置段加入：

```ini
sslverify=false
```

> **安全提示：**`sslverify=false` 会关闭远程服务器的 SSL 证书校验，降低软件包下载过程的安全性。请仅在可信网络中临时使用，不要在 `/etc/dnf/dnf.conf` 中进行全局长期配置。证书问题修复后，应删除该配置并恢复 SSL 证书校验。

### 安装结果

|路径                                     |用途         |
|:----------------------------------------|:-----------|
| /usr/local/sbin/ubs-opt        | 性能数据采集        |
| /usr/local/sbin/ubs-opt-guard | 性能数据处理        |
| /usr/local/sbin/ubs-opt-tuner       | 优化分析 |
| /usr/local/sbin/ubs-optimizer/config.json  | 配置文件 |

### ubs-optimizer进程管理

- 启动进程

   - 虚拟机内启动采集进程：

      ```bash
      ubs-opt start_ebpf
      ```

   - 物理机内启动性能分析：

      ```bash
      ubs-opt-tuner start
      ```

- 停止进程

   虚拟机内停止采集进程：

   ```bash
    ubs-opt stop_ebpf
   ```

### 软件卸载

- 停止进程

   虚拟机内执行：

   ```bash
    ubs-opt stop_ebpf
   ```

- 卸载软件

   - 虚拟机内执行
   
      ```bash
      rpm -e ubs-optimizer
      ```

   - 物理机内执行

      ```bash
      rpm -e ubs-optimizer
      ```
