# 构建指导

本文介绍 `virt-optimizer` 组件的两种构建方式：

* 方式一：基于 openEuler 24.03 基础环境构建
* 方式二：基于预编译镜像环境构建

## 1. 基于 openEuler 24.03 基础环境构建

### 1.1 基础环境要求

* 推荐操作系统：openEuler 24.03 LTS SP4
* 操作系统版本要求：openEuler 24.03 LTS SP3 及以上版本，内核版本为 6.6
* 支持的 CPU 架构：`x86_64`、`aarch64`

### 1.2 内核配置要求

物理机和虚拟机需要启用必要的 eBPF 相关内核配置。

执行以下命令检查内核配置：

```bash
zcat /proc/config.gz | grep DEBUG_INFO
```

输出中应包含：

```text
CONFIG_DEBUG_INFO=y
CONFIG_DEBUG_INFO_BTF=y
```

> 若当前操作系统未启用上述 eBPF 相关配置，需要调整内核配置并重新编译、安装内核。

同时，建议确认当前系统存在可用的 BTF 信息：

```bash
ls -l /sys/kernel/btf/vmlinux
```

也可以使用 `bpftool` 验证 BTF 数据是否能够正常解析：

```bash
bpftool btf dump file /sys/kernel/btf/vmlinux format c >/dev/null
echo $?
```

返回值为 `0` 表示 BTF 数据可以正常解析。

### 1.3 软件依赖

构建 `virt-optimizer` 需要安装以下软件包：

| 软件包             | 版本要求         |
| :-------------- | :----------- |
| git             | 2.33.0 及以上版本 |
| cmake           | 3.22.0 及以上版本 |
| make            | 4.3 及以上版本    |
| gcc             | 10.3.1 及以上版本 |
| g++             | 10.3.1 及以上版本 |
| rapidjson-devel | 1.1.0 及以上版本  |
| bpftool         | 7.2.0 及以上版本  |
| libbpf          | 0.8.1 及以上版本  |
| libbpf-devel    | 0.8.1 及以上版本  |
| clang           | 12.0.1 及以上版本 |
| tar             | 1.34 及以上版本   |
| rpm-build       | 4.18.2 及以上版本 |

### 1.4 获取源码

执行以下命令获取源码：

```bash
git clone https://gitcode.com/openeuler/ubs-virt.git
cd ubs-virt/virt-optimizer
```

### 1.5 执行构建

执行构建脚本：

```bash
bash build.sh
```

构建成功后，RPM 产物位于：

```text
ubs-virt/virt-optimizer/output/release/
```

RPM 文件名格式为：

```text
ubs-optimizer-<version>-<release>-<arch>.rpm
```

其中 `<arch>` 为 `x86_64` 或 `aarch64`。

## 2. 基于预编译镜像环境构建

预编译镜像中已经安装 `virt-optimizer` 编译构建所需的软件依赖，可以直接基于该镜像启动容器并执行构建，从而减少基础环境准备工作。

> 容器与宿主机共享 Linux 内核，因此 eBPF、BTF 等内核能力仍由宿主机提供。使用预编译镜像时，应确保宿主机具备相应的内核能力。

### 2.1 下载预编译镜像

执行以下命令：

```bash
docker pull swr.cn-north-4.myhuaweicloud.com/ubscore/ubs-virt:oe2403-v1
```

### 2.2 启动构建容器

执行以下命令启动容器：

```bash
docker run -it \
    --name=ubs-virt \
    swr.cn-north-4.myhuaweicloud.com/ubscore/ubs-virt:oe2403-v1 \
    /bin/bash
```

对于仅执行 `virt-optimizer` 源码编译和 RPM 构建的场景，无需额外挂载宿主机驱动目录。

### 2.3 获取源码

进入容器后，执行：

```bash
cd /home
git clone https://gitcode.com/openeuler/ubs-virt.git
cd ubs-virt/virt-optimizer
```

### 2.4 执行构建

执行构建脚本：

```bash
bash build.sh
```

构建成功后，RPM 产物位于：

```text
ubs-virt/virt-optimizer/output/release/
```

RPM 文件名格式为：

```text
ubs-optimizer-<version>-<release>-<arch>.rpm
```

其中 `<arch>` 为 `x86_64` 或 `aarch64`。
